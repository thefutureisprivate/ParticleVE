# Security Policy

If you find a security issue or vulnerability, public disclosure is allowed.

Coordinated disclosure is appreciated, but not required. You can report issues
in [this repository](https://github.com/thefutureisprivate/particleve/issues) or
contact [the maintainer](https://github.com/thefutureisprivate) through the public
contact links on the maintainer's profile.

Report vulnerabilities in upstream dependencies to their maintainers as
appropriate, and describe any ParticleVE integration impact in the project report.
